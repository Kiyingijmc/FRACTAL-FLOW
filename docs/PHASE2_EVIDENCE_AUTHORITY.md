# Phase 2 Evidence Authority Taxonomy

Phase 2 distinguishes observations, evidence, context, validity gates, and
semantic interpretation. Availability of an output does not make its producer an
evidence authority.

| Component | Semantic role | Evidence authority |
|---|---|---|
| Data Quality | validity / fail-closed gate | No |
| Volatility | context / normalization | No |
| Structure | committed structural evidence | Yes |
| Flow | directional pressure evidence | Yes |
| Regime | contextual regime evidence | Yes, bounded |
| PDE | episode / recovery evidence | Yes |
| Location | geometric context/evidence | Yes, bounded |
| Role | semantic classification | No; interpretation authority |
| EvidenceAggregator | evidence aggregation authority | Yes, aggregation only |

Correlation groups and family caps prevent multiple projections of the same
information from becoming independent authority. Risk and execution authority
remain outside Phase 2.
